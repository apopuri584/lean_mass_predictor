# lean_mass_predictor
This project takes uses the NHANES 2017 - 2018 dataset to train a Random Forest Regressor Model to build a Lean Mass Predictor. The predictor takens in basic body demographics, nutrition intake, and daily activity time to predict how much lean mass a person has. To use the lean mass predictor, open the colab file, press run all, and enter your statistics in the last cell.
